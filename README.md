# JML 프롬프터 업데이트 안내

이 저장소에는 업데이트 버전과 변경 이력을 게시합니다. 설치 파일은 허용된 GitHub 계정으로 로그인하고 저장소 초대를 수락한 뒤 다운로드할 수 있습니다.

[최신 설치 파일 다운로드](https://github.com/skw1010/jml-prompter-downloads/releases/latest)

## 버전별 변경 사항

### 1.0.12
- 편집 화면에서 선택한 글자의 취소선을 체크박스로 적용하거나 해제합니다.

### 1.0.11
- Word 문서의 색상, 굵게, 기울임, 취소선, 밑줄과 글꼴을 불러옵니다.
- 기본 검정색은 프로그램에서 설정한 글자색을 따릅니다.

### 1.0.10
- 빈 줄을 지나 다음 대본으로 천천히 스크롤합니다.
- 괄호 안 참고 내용은 화면에 표시하고 음성 인식 대본 비교에서 건너뜁니다.

### 1.0.9
- 발화 감지 중 5초 동안 인식 결과가 없으면 재연결합니다.
- 설치 폴더에 음성인식 진단 로그를 저장합니다. 음성과 대본은 기록하지 않습니다.
- 업데이트 다운로드 페이지를 열 때 프로그램 종료를 시도합니다.

### 1.0.8
- 조작 화면과 별도로 두 번째 화면에 반전된 거울 출력을 제공합니다.

### 1.0.7
- 설정창을 기본으로 숨기고 설정과 대본 불러오기 버튼을 오른쪽 상단에 배치했습니다.

### 1.0.6
- 음성인식 연결이 5초 동안 응답하지 않으면 다시 시도합니다.

### 1.0.5
- 음성인식 연결이나 마이크 연결이 일시 중단되면 다시 연결합니다.

### 1.0.4
- 대본 문단 사이 빈 줄이 표시와 편집 후에도 유지되도록 수정했습니다.

### 1.0.2
- 설치 파일을 허용된 GitHub 계정 전용 비공개 저장소로 이전했습니다.
- 프롬프터 로고를 설치 파일과 프로그램 아이콘에 적용했습니다.

각 버전의 상세 안내는 [릴리스 목록](https://github.com/skw1010/jml-prompter-windows/releases)에서 확인할 수 있습니다.
