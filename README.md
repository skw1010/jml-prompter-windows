# JML 프롬프터 · Windows

[최신 Windows 설치 파일 받기](https://github.com/skw1010/jml-prompter-windows/releases/latest)

Windows 10/11 64비트, Google Chrome, 음성 따라가기용 마이크가 필요합니다. 릴리스에서 이름이 Setup.exe로 끝나는 파일을 내려받아 설치한 뒤 바탕화면의 JML Prompter를 실행하세요. 설치 파일은 코드 서명되지 않았습니다.

TXT 또는 DOCX 대본을 불러오거나 붙여 넣고, 프롬프터 화면에서 읽을 위치에 커서를 둔 뒤 시작하세요. 처음 사용할 때 Chrome에서 마이크 사용을 허용하세요. 대본과 설정은 이 PC의 앱 전용 브라우저 프로필에 저장됩니다. 웹 버전에서 작업 중인 대본은 TXT로 내보낸 뒤 불러올 수 있습니다.

대본 편집과 수동·일정 속도 스크롤은 인터넷 없이 사용할 수 있습니다. Chrome의 기본 음성인식과 GitHub 업데이트 확인에는 인터넷이 필요합니다.

시작할 때마다 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 변경 사항을 보여 줍니다. 다운로드 페이지를 열어 설치 파일을 받은 뒤 프롬프터를 종료하고 설치하세요. 인터넷 연결이 없어도 프로그램은 열립니다.

Windows 설정의 설치된 앱에서 JML Prompter를 제거할 수 있습니다. 앱 전용 프로필은 다음 설치에서도 대본과 설정을 사용할 수 있도록 보관합니다.
